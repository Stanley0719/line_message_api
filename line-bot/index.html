LINE 會議助理

這是 LINE Messaging API Webhook 後端，不是網頁聊天機器人。完成部署與 LINE 設定後，就能直接在 LINE 官方帳號聊天記錄會議。

設定步驟

  1. 在 LINE Developers Console 建立 Messaging API Channel，取得 Channel Secret 和 Channel Access Token。
  2. 部署 line-bot/server.py 至支援 Python 的公開 HTTPS 主機，並設定兩個 LINE 金鑰環境變數。
  3. 在 LINE Developers Console 將 Webhook URL 設為 https://你的網域/callback，通過 Verify 後啟用 Use webhook。
  4. 將官方帳號加入好友，傳送「記錄會議」開始使用。

完整部署步驟與環境變數請參閱 README。

會議需要名稱、時間和地點；缺少欄位時 Bot 會逐項詢問。請勿把 Channel Secret 或 Access Token 放入網頁或提交至 Git。請使用持久化磁碟儲存 SQLite 資料庫。
