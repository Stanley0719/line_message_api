LINE 餐廳訂位

這是 LINE Messaging API Webhook 後端。完成部署與 LINE 設定後，顧客可在官方帳號對話完成訂位，餐廳則可登入後台查看每日訂位。

設定步驟

  1. 在 LINE Developers Console 建立 Messaging API Channel，取得 Channel Secret 和 Channel Access Token。
  2. 部署 line-bot/server.py 至支援 Python 的公開 HTTPS 主機，設定 LINE 金鑰及後台帳密環境變數。
  3. 在 LINE Developers Console 將 Webhook URL 設為 https://你的網域/callback，通過 Verify 後啟用 Use webhook。
  4. 將官方帳號加入好友，傳送「訂位」開始預約。餐廳後台網址為 https://你的網域/admin。

完整部署步驟與環境變數請參閱 README。

Bot 會詢問日期、時間、人數、姓名、聯絡方式及特殊需求；每桌保留 90 分鐘，營業時間為 11:30–14:30、17:00–20:00。請勿把任何金鑰或後台密碼放入網頁或提交至 Git，並使用持久化磁碟儲存 SQLite 資料庫。
